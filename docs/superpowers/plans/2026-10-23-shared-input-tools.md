# 共用输入分析工具迁移计划

**目标：** 将已用于多款游戏的容器/ExeFS、NSO 和依赖图实现从 `games/totk/scripts` 提升到 `game_tools`，保持现有构建入口和输出语义。

**约束：** 不在源码树复制实现；《王国之泪》原脚本路径保留薄兼容入口，原构建器无需改命令。构建时把共用工具复制进项目外工作目录。检查器直接使用共用实现。只移动源码与测试，不在项目内生成游戏数据或构建产物。迁移不触及游戏运行热路径。

1. 增加失败测试：共用模块可导入、共用提取命令可处理合成 NSP、兼容入口导出相同函数。
2. 移动三个实现脚本到 `game_tools`，在原路径留下命令行和导入兼容入口；检查器改用共用路径。
3. 用真实 `prepare_work` 拷贝建立项目外工作目录，确认复制后的三个兼容命令可启动；发现缺少共用工具时先增加失败测试，再补构建时同步。
4. 运行目标测试和全量测试，对马里奥本体/更新包及至少一款既有游戏作真实只读复验；核对报告身份、外部临时清理和源码目录无产物。
