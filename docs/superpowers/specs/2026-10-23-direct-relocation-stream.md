# 直接读取映像重定位表：离线验证阶段

## 目标

验证装载器可以从已验证的改写映像直接遍历 RELR、RELA 与 PLT RELA，避免把同一批重定位再编成约 24 字节/条的 C 数组。先提供独立、无游戏专用地址的 C 读取器及测试；不替换现有游戏的装载循环，不生成 App，也不宣称启动或帧时间改善。

## 安全边界

输入是已通过 `runtime_preflight.py` 哈希和结构检查的映像，以及该检查解析出的表偏移、大小、符号数、数据段与键页边界。读取器仍核对每个表的范围、24/8 字节条目长度、支持的 AArch64 重定位类型、符号下标、写入地址和相对加数。为保证回调写入数据段时不会覆盖未读的源记录，所有源表必须完整落在数据段之前；其他布局拒绝，下一阶段再决定是否复制或另设格式。

## 验证与性能

合成样本覆盖 RELR 直接项/位图、RELA 与 PLT、损坏边界和回调停止。真实马里奥本体在项目外临时目录重建改写映像，C 读取器的总数与类型分布和 Python 静态检查逐一对拍。只测内存中遍历的离线耗时，并记录原表与平铺副本的字节数；实际 App 启动、服务绑定、NVN 与帧时间需要后续实机验证。
