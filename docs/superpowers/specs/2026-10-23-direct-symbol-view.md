# 直接读取映像动态符号表：离线验证阶段

## 目标

在已验证的改写 NSO 映像上直接读取 `.dynsym/.dynstr`，为共用装载器提供零拷贝符号行和名称，以及一个只存符号下标的查找索引。对照当前装载器保持 `FNV-1a`、线性探测、跳过保留的 0 号符号、同名首个定义优先和越过键页边界时查找失败的语义。本阶段不替换现有游戏装载器。

## 输入和边界

输入偏移、长度、符号数和段边界来自离线哈希及结构预检。C 读取器仍逐项核对整张符号表和字符串表位于映像及可写数据段之前；逐个符号名必须落在字符串表内并以 NUL 终止。索引由调用方提供连续空间，以便装载器控制分配和释放；映像必须在索引与名称使用期间保持有效。预检严格接受 UTF-8 符号名，避免 Python 替换损坏字节后与 C 名称查找不同。

## 验证和成本

合成表覆盖导入、重复定义、保留 0 号、无效定义地址、边界与损坏名称。真实马里奥本体在项目外重建改写映像，对每个符号行和每个不同定义名与 Python 预检逐项对拍，并测量索引构建与查找的离线内存耗时。记录原始表字节数、索引空间和可能省去的额外平铺符号行字节；不据此宣称 App 启动或帧时间改善。
