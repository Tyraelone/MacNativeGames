# 描述表驱动的共用模块链接入口

## 目的

将已验证的精简模块描述表接到共用符号视图、同包符号解析和流式重定位写入，不再由测试命令逐个传入表偏移。入口只负责已映射、已核对 SHA-256 的模块数据；映射、宿主服务、构造器和图形初始化仍由调用方负责。现有游戏装载器不切换，以免在缺少实机运行环境时改变已上线行为。

## 接口与边界

调用方按描述表顺序提供映像、基址和符号索引工作区。准备阶段一次性核查描述表、符号及重定位源表、门边界并建立索引；所有模块准备成功后才能进入链接阶段。链接阶段复用已有的 host-first 符号解析规则，顺序应用重定位，无平铺表、无逐条堆分配。任何写入阶段失败都会让映像成为不可重试状态，调用方须丢弃并从已验证原图重新装载。

模块描述表中的摘要仅是预期值。正式装载器必须在准备阶段之前核对实际映像 SHA-256；离线驱动也先核对原始 NSO 和改写映像哈希。调用方仍决定宿主覆盖回调及其 ABI。此入口不推断弱符号置零后调用是否安全。

## 证明与性能

合成 C 用例覆盖模块顺序、跨模块导入、host 优先、弱置零、损坏表、工作区不足和写入失败后的计数。马里奥本体在源码目录外重新改写、生成描述表，再用该入口完成全部重定位，逐模块对比独立 Python 平铺写入后的完整映像 SHA-256，并记录额外工作区与链接耗时。耗时只反映离线内存操作，不是 App 启动或帧时间。
