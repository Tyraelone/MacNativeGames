# 共用模块符号解析：离线装载验证

## 目标

把已验证映像的符号视图接到共用重定位写入核心，按现有装载器的规则解析同包模块地址，并对马里奥本体的真实 `main/sdk` 重定位序列核对最终数据。现阶段只验证模块地址、弱置零和可选宿主回调的优先级，不声称任一宿主函数已经实现了正确语义，也不启动游戏。

## 解析顺序

对每个非相对重定位，先调用可选宿主回调；它由具体游戏装载器负责实现观察门、宿主覆盖和栈包装。若回调未提供地址，本模块非弱定义优先使用本模块地址；否则按既定模块顺序查找第一个有效定义。仍未找到时，弱符号写零，强符号报错。模块内同名首定义取胜，首定义地址越界时不回退到同名后项。所有地址计算检查越界。解析器记录四类次数，便于与离线预检对拍。

## 输入与验证

模块集、顺序、哈希和表布局来自已有离线预检。合成测试覆盖本地强定义、全局查找、弱置零、宿主优先、无效首定义和强缺失。真实马里奥本体只在项目外重建改写映像，以固定且不相交的测试基址装载并应用所有重定位；C 输出完整映像的 SHA-256 与独立 Python 平铺表计算结果一致才通过。记录一次性装载耗时与弱置零数；该耗时不含真实内存映射、宿主服务、构造器或帧循环。现有游戏装载器保持不变。
