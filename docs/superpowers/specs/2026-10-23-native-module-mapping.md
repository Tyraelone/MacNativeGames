# 通用原生模块映射与封页

## 目标

在现有精简描述表及共用链接入口之上，增加 macOS 原生内存映射阶段。它读取项目外已改写映像、核对文件大小和 SHA-256，映射为可写的私有内存；全部模块成功链接后，再按主机页粒度把文字与跳板页设为 RX、只读数据的完整页与密钥区域设为 R、数据页保留 RW。该阶段不执行游戏代码，不改变现有三款游戏的装载器。

## 安全和所有权

只接受非符号链接的普通文件，拒绝不匹配的大小或摘要；失败时解除映射，不留下部分成功的句柄。映射字节和描述表须在链接期间保持有效。封页前要求相同映射对应的链接上下文已经成功完成预期数量的重定位。每个权限区间按系统实际页大小取整，拒绝会让可写页与可执行页重叠的边界。若客体段边界落在主机页内，文字末页可能包含可执行的只读段前缀，数据首地址所在页可能包含可写的只读段尾部；这是页粒度所限，映射器须维持无 W+X。调用方负责释放映射；封页或链接失败后不得继续执行该映像。

描述表允许 `patch_off == file_size` 表示没有补丁代码；此时尾部至映射边界保持只读，不设置空的 RX 区间。

## 证据与性能边界

合成模块测试哈希错误、文件大小不匹配、符号链接、布局边界、无补丁区域、链接前封页及页权限。马里奥本体由项目外的真实改写映像生成描述表，经过映射、链接和封页后逐页核对实际主机权限，把完整映像输出到项目外，并与独立 Python 按实际映射基址写入的结果对比 SHA-256。记录离线各阶段耗时；不据此推断 App 冷启动、图形路径或逐帧表现。
